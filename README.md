# TON NFT Monitor Bot

Telegram-бот на **aiogram 3** для мониторинга NFT-коллекций в сети TON через
**TonAPI**. Отслеживает покупки, действия на маркетплейсе (листинги, ставки,
изменение цены) и прямые передачи NFT, мгновенно присылая уведомления
подписчикам со ссылкой на Getgems.

## Структура проекта

```
ton-nft-bot/
├── main.py            # точка входа: бот + мониторинг + health-check сервер
├── config.py           # переменные окружения и константы
├── handlers.py        # команды бота (/start, /status, /test, /add, /list)
├── monitor.py          # опрос TonAPI, классификация событий, рассылка
├── storage.py          # хранение подписчиков и состояния в JSON
├── tonapi.py            # обёртка над TonAPI
├── requirements.txt
├── .env.example
└── data/
    ├── subscribers.json   # база подписчиков (создаётся автоматически)
    └── state.json          # прогресс мониторинга (создаётся автоматически)
```

## Команды бота

| Команда         | Доступ   | Описание                                                        |
|-----------------|----------|------------------------------------------------------------------|
| `/start`        | все      | Регистрирует пользователя и показывает его Telegram ID           |
| `/status`       | все      | ID, статус админа, кол-во подписчиков, всего обработано событий   |
| `/test`         | админ    | Рассылает тестовое уведомление о сделке всем подписчикам          |
| `/add <ID>`     | админ    | Добавляет Telegram ID вручную                                     |
| `/list`         | админ    | Показывает список всех подписчиков                                 |

## Установка и запуск локально

1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
2. Скопируйте `.env.example` в `.env` и заполните:
   - `BOT_TOKEN` — токен от [@BotFather](https://t.me/BotFather)
   - `ADMIN_ID` — ваш Telegram ID (узнать у [@userinfobot](https://t.me/userinfobot))
   - `TONAPI_KEY` — (не обязателен) ключ с [tonconsole.com](https://tonconsole.com), повышает лимиты запросов
   - `NFT_COLLECTIONS` — адреса коллекций через запятую
3. Запустите:
   ```bash
   python main.py
   ```
