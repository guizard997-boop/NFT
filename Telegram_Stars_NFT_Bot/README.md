# Telegram Stars & Gifts NFT Tracker Bot

Данный бот предназначен для поиска и отслеживания объявлений о продаже NFT и подарков (Gifts) за **Telegram Stars (Звёзды)** в указанных Telegram-каналах и чатах.

## Настройка и запуск

1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

2. Настройте конфигурационные переменные в файле `main.py`:
   - `API_ID` и `API_HASH` — получите на [my.telegram.org](https://my.telegram.org)
   - `BOT_TOKEN` — получите у [@BotFather](https://t.me/BotFather)
   - `TARGET_CHAT_ID` — ID канала или чата, куда бот будет присылать найденные объявления.
   - `MONITORED_CHATS` — список юзернеймов каналов/чатов для мониторинга.

3. Запустите бота:
   ```bash
   python main.py
   ```

## Возможности:
- Автоматический поиск по ключевым словам и ценам в Stars (`⭐️`).
- Отображение `@username` продавца или прямой кликабельной ссылки на его профиль.
- Уведомления в целевой чат с прямыми ссылками на лоты.
